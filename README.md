# Safety

Construction safety awareness quiz app for toolbox meetings.

## Included

- Worker mode and organizer mode
- Multilingual quiz: English, Chinese, Tamil, Bengali
- Session ID workflow
- QR code generation
- Google Sheets backend via Apps Script
- Organizer leaderboard
- CSV export
